Olingan sana: 2026-04-24

Tuzilish:
- heisallah_full.db       SQLite database (hamma narsa)
- raw_api/*.json          API dan olingan xom 16 tildagi javoblar (to'liq dump)
- json/*.json             Ilova ishlatadigan ma'lumotlar (arab + rus)

- csv/*.csv               Har jadval CSV (UTF-8-BOM, Excel ochadi)

    + names_all_languages.csv      — 100 ism 16 tilda matrix
- excel/he_is_allah_arabic.xlsx    — arab-yo'naltirilgan (4 varaq)
- excel/he_is_allah_all_languages.xlsx — har til alohida varaq
- voices/*.mp3            — 100 audio tilovat
- images/*.jpg            — 100 fon rasm
- images/*.svg            — 100 kalligrafiya

- raw_api/, csv/, excel/: 16 tilda to'liq 1600 ta tarjima
